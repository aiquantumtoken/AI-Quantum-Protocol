Frequently Asked Questions

Everything you need to know about post-quantum cryptography, agent vaults, and $AIQT economics.

What is AI Quantum Protocol ($AIQT)? +
$AIQT is the first post-quantum machine-to-machine (M2M) settlement currency and smart custody layer built natively on Solana (Token-2022). It protects autonomous AI agents from future quantum attacks while providing sub-second micropayments with an immutable 0.5% deflationary burn.
Why do 24/7 autonomous AI agents need post-quantum security? +
Unlike humans who store keys offline on a Ledger, autonomous AI agents operate 24/7 on servers, keeping hot private keys in memory to sign thousands of automated transactions. Every transaction exposes their public key in the mempool. Standard Solana accounts rely on Ed25519 (elliptic curves), which Shor's algorithm solves in polynomial time. Once quantum computing reaches scale, every single agent treasury will be drained unless protected by post-quantum lattice cryptography.
How does the Dual-Tier Quantum Vault solve signature bloat? +
Post-quantum signatures (like NIST ML-DSA) are ~3,300 bytes (50x larger than Ed25519). If every small transaction used them, Solana's TPS would plummet. $AIQT introduces a Dual-Tier state machine:

• Tier 1 Fast Path (< 10,000 $AIQT): Sub-second execution (~400ms) on Ed25519 for routine micropayments (64 bytes).
• Tier 2 Quantum Shield (≥ 10,000 $AIQT): Mandatory NIST FIPS-204 ML-DSA Lattice Dual-Lock. High-value treasury transfers are 100% immune to Shor's algorithm.
How does the 0.5% M2M deflationary burn work? +
$AIQT is deployed using Solana Token-2022's native TransferFeeConfig extension. Every time an agent hires another agent or pays an API fee, an immutable 0.5% (50 bps) protocol fee is processed on-chain. 50% is permanently incinerated to the Solana dead address (1111...1111), and 50% funds autonomous agent compute/GPU resources.
Can the team mint more tokens or freeze wallets? +
No. The Mint Authority is revoked immediately following the 1 Billion genesis mint, making inflation mathematically impossible. The Freeze Authority is completely disabled (None), guaranteeing that user and agent wallets can never be frozen or blacklisted. The protocol achieved a 100/100 Clean score in our pre-launch security audit.
How do external developers use the SDK and ElizaOS plugin? +
Developers can install @aiqt/agent-sdk or @aiqt/plugin-solana-quantum via npm to automatically grant any AI agent post-quantum lattice commitments and M2M fee calculation in 3 lines of code.
